# Test technique de Stretch & Water pour Windows

Il s’agit d’une version préliminaire destinée à vérifier la fenêtre et l’icône, pas encore de l’application complète. Elle affiche une image fixe pendant 10 secondes. Elle ne comprend pas de rappels automatiques, de son ni de préférences. Merci de faire le test et de transmettre vos observations à Melina.

## Avant de commencer

Il vous faut Windows 11 64 bits sur un processeur Intel ou AMD. Avec deux écrans, vous pourrez également tester le placement. Une fois installée, cette version fonctionne sans compte ni navigateur externe. Si Windows demande le composant Microsoft Edge WebView2, suivez les indications affichées ; son installation peut nécessiter une connexion ou une autorisation.

## Installer et ouvrir

1. Sur la page de la version de test transmise par Melina, téléchargez le programme d’installation dont le nom se termine par `-setup.exe`. Ne choisissez pas les fichiers « Source code ».
2. Ouvrez le fichier téléchargé et suivez les étapes. L’application s’installe pour votre compte utilisateur.
3. Cette version de test ne possède pas de signature numérique d’un éditeur vérifié : Windows ou SmartScreen peut afficher un avertissement. Vérifiez que le téléchargement provient bien du lien fourni par Melina. Si votre ordinateur ou son administrateur empêche l’ouverture, ne modifiez pas les paramètres de sécurité : transmettez le message à Melina et arrêtez le test.
4. Ouvrez « Stretch Water Windows PRUEBA » depuis le menu Démarrer. Cherchez son icône près de l’horloge ; elle peut se trouver derrière la flèche des icônes masquées.

## Tests à effectuer

1. Cliquez sur l’icône et choisissez « Probar figura / Tester ». Dans les 5 secondes qui suivent, déplacez le curseur sur l’écran à tester. L’image y apparaît-elle en bas à droite pendant environ 10 secondes, sans fond rectangulaire ni bordure ?
2. Recommencez en écrivant dans votre propre fenêtre. Pouvez-vous continuer à écrire ? Cliquez sur une zone de votre fenêtre située derrière l’image. Le clic atteint-il votre fenêtre ?
3. Si vous avez deux écrans, lancez le test puis, pendant les 5 secondes d’attente, placez le curseur sur l’un. Recommencez sur l’autre. L’image apparaît-elle sur l’écran où se trouve le curseur et y reste-t-elle jusqu’à la fin ? Si vous n’avez qu’un écran, indiquez « non testé ».
4. Recommencez plusieurs fois. L’image apparaît-elle et disparaît-elle à chaque fois ? Dans le menu, choisissez « Salir / Quitter » et vérifiez que l’icône disparaît.
5. Pour retirer le test, ouvrez Paramètres → Applications → Applications installées, cherchez « Stretch Water Windows PRUEBA » et choisissez Désinstaller.

## Retour à envoyer à Melina

Indiquez par écrit la version de Windows et le nombre d’écrans. Pour chaque point, précisez « réussi », « échec » ou « non testé », avec une brève explication. Recopiez tout message d’erreur ou d’avertissement. Aucun mot de passe, fichier personnel ou capture d’écran n’est nécessaire.
